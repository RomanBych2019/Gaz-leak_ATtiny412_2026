# Контроллер датчика газа на ATtiny412

Назначение выводов:

- PA0: UPDI
- PA1: светодиод состояния платы
- PA2: вход АЦП датчика с внешней подтяжкой 4.7 кОм к GND
- PA3: отладочный TX, программный UART 2400 бод
- PA6: выход силового ключа 2
- PA7: выход силового ключа 1

Основная логика:

- после прогрева выполняется первоначальная калибровка чистого воздуха;
- новое значение сравнивается с сохраненным в EEPROM: если разница не больше допустимой, оно применяется и записывается; если разница большая, используется сохраненное значение;
- обрыв датчика или замыкание линии на GND определяется по АЦП около 0 В;
- замыкание выхода датчика на питание определяется по АЦП около +5 В;
- в LIN-варианте PA7 управляет BTS4142N; программная проверка замыкания нагрузки и повторные включения не выполняются;
- состояние ALARM защелкивается до перезапуска питания контроллера;
- неисправности датчика являются восстанавливаемыми.

Автокалибровку можно отключить на этапе компиляции в `src/main.cpp`:

```cpp
#define AUTOCALIBR 0
```

При отключенной автокалибровке используются фиксированные заводские пороги АЦП.

Для выбора поведения PA6/PA7 измените `SENSOR_MODIFICATION` в `src/main.cpp`.

Варианты сборки:

- `attiny412`: распиновка базовой платы;
- `attiny412_lin`: распиновка платы с LIN-драйвером, сборка с `LIN_DRIVER`.

Сборка:

```sh
pio run -e attiny412
pio run -e attiny412_lin
```

Прошивка:

Проект использует `serialupdi`. Скорость загрузки задана в `platformio.ini`:
`upload_speed = 19200`.

Обычная версия:

```sh
pio run -e attiny412 -t upload
```

LIN-версия:

```sh
pio run -e attiny412_lin -t upload
```

Если программатор не определяется автоматически, укажите порт в `platformio.ini`:

```ini
upload_port = /dev/cu.usbserial-4
```

## Ограничение LIN_DRIVER

LIN-версия занимает `3296/4096` байт flash, свободно 800 байт
при текущих настройках (`MOD_SINGLE_LOW`, `DEBUG=0`, `AUTOCALIBR=0`).
При любом повторном запросе на изменение LIN-версии необходимо до внесения
изменений предупредить оператора об ограниченном резерве flash. Если новый код
не помещается, нужно согласовать, какой существующий функционал можно удалить или
упростить.

## LIN-вариант

- трансивер: TLIN2029ADRBRQ1;
- скорость обмена: 19200 бод;

- PA0: UPDI
- PA1: LIN TXD
- PA2: LIN RXD 
- PA3: светодиод состояния платы/отладочный TX, программный UART 2400 бод
- PA6: вход АЦП датчика с внешней подтяжкой 4.7 кОм к GND
- PA7: выход управления силовым ключом BTS4142N (через R6 на вход IN)

- статусный кадр: LIN ID `0x12`, PID `0x92`, enhanced checksum;
- данные ответа: `state`, `flags`, `adc_l`, `adc_h`;
- `flags`: bit0 = ALARM защелкнут, bit1 = выход PA7 активен, bit2 = неисправность, bit3 = прогрев; биты 4–7 зарезервированы и равны 0.
